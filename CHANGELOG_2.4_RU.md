# Game Audio Bridge 2.4 — журнал изменений

## Изменение маршрута OpenAL

- Для входных IEEE Float32, IEEE Float64 и signed PCM Int64 больше нет отказа только потому, что OpenAL не имеет стандартного многоканального enum для signed PCM Int32.
- Эти три формата преобразуются в signed PCM Int32 внутри `ConvertBuffer`.
- На границе вызова `alBufferData` PCM Int32 промежуточные данные нормализуются в Float32, поскольку стандартные многоканальные OpenAL enum 32-bit обозначают именно Float32, а не signed PCM Int32. Целочисленные данные не маркируются ошибочно как Float32.
- Для поддерживаемых OpenAL раскладок 1/2/4/6/7/8 каналов сохраняются число каналов, частота дискретизации и порядок семплов/каналов; DownMix и ресемплинг не выполняются.
- Для WASAPI → OpenAL больше не требуется, чтобы строка производителя OpenAL содержала Creative: используется успешно открываемое системное OpenAL-устройство. Проверка Creative остаётся диагностической и используется в отдельном нативном FMOD-пути.
- В `ReadSample` добавлено чтение signed PCM Int64 для пути ASIO, чтобы разрешённый формат не читался как нулевые семплы.

## Важные ограничения

- «Всегда разрешать OpenAL» означает, что GAB не блокирует Float32/Float64/Int64 из-за отсутствия signed-PCM32 enum. Это не может гарантировать вывод, если OpenAL-устройство не открывается, OpenAL отвергает формат/частоту, не поддерживается раскладка каналов или драйвер выдаёт ошибку.
- В этом коде для 32-bit OpenAL payload используется Float32 на границе API. Поэтому пользовательское требование о PCM Int32 реализовано как промежуточное преобразование, но OpenAL получает корректно обозначенный Float32-буфер. Передача PCM Int32 под float enum была бы ошибкой.
- Остальные форматы не преобразуются в `ConvertBuffer`, но OpenAL-маршрут по-прежнему имеет явные ограничения по доступным enum: pass-through реализован для PCM16 и Float32, а Float32/Float64/Int64 используют селективный путь PCM32 → Float32. Форматы вроде PCM24/PCM32 пока не имеют отдельного точного маршрута.
- Это исходный код, не готовая проверенная сборка. Компиляция Windows DLL и проверка на Creative Sound Blaster X-Fi в этой среде не выполнялись.
