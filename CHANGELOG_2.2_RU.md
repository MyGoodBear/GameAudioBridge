# Game Audio Bridge 2.2 — формат OpenAL и журнал

## Изменения
- Журнал `GameAudioBridge.log` записывается в корневую папку Game Audio Bridge, а не в `%TEMP%`.
- После запуска игры подробное окно аудиомонитора автоматически не открывается. Его можно открыть кнопкой «Аудиомонитор».
- Основная строка состояния периодически читает журнал и показывает обнаруженный WASAPI-формат либо последнее существенное предупреждение.
- Удалена проверка многоканального потока по встроенному списку допустимых масок каналов. Для 32-битного Float добавлены соответствующие enum-значения `AL_EXT_MCFORMATS` для 4/6/7/8 каналов.
- Для передачи не выполняются скрытое сведение каналов, изменение разрядности или преобразование sample type. Если у OpenAL нет подходящего enum либо драйвер отклоняет буфер, причина записывается в журнал, а GAB не должен объявлять перенаправление успешным.

## Важные ограничения
OpenAL не предоставляет универсальный enum, описывающий абсолютно любой формат WASAPI. Поэтому требование «любой формат без исключений» невозможно гарантировать на уровне `alBufferData`: API и реализация OpenAL должны иметь формат, который соответствует исходным данным. Для неизвестных sample type или числа каналов, для которого нет соответствующего OpenAL enum, мост всё ещё не может корректно передать буфер без преобразования. В таких случаях исходный WASAPI-путь сохраняется, а предупреждение должно быть видно в строке состояния и подробном журнале.

## Проверка
Исходники изменены, но этот архив не содержит подтверждённой Windows-сборки и не является доказательством работы на Creative X-Fi Elite Pro. Необходимо собрать в Windows с MSVC/CMake и проверить Crysis x86, в частности WASAPI `8 каналов / 44100 Гц / Float32`, а также фактические ошибки `alBufferData` и слышимый выход.
