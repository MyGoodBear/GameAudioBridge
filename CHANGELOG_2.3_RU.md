# Game Audio Bridge 2.3 — журнал изменений

## Выборочное преобразование аудиоформатов

- Добавлен код преобразования Float32 → signed PCM Int32.
- Добавлен код преобразования Float64 → signed PCM Int32.
- Добавлен код преобразования signed PCM Int64 → signed PCM Int32 (сохранение старших 32 бит).
- Остальные форматы в преобразователе копируются без изменения байтов.
- Частота дискретизации, число каналов и порядок каналов не изменяются.
- Float NaN преобразуется в 0; значения за пределами [-1, +1] ограничиваются пределами signed PCM Int32.
- Добавлена безопасная блокировка OpenAL-перенаправления, если для signed PCM Int32 нет документированного соответствующего формата. Формат 32-bit из AL_EXT_MCFORMATS нельзя автоматически считать signed PCM Int32: это не даёт права передавать integer-буфер под float enum.

## Ограничение

Стандартный OpenAL маршрут этого проекта не подтверждает поддержку signed PCM Int32 для многоканального вывода. Поэтому потоки, которым требуется это преобразование, остаются на исходном WASAPI пути, пока не будет реализован отдельный подтверждённый backend/extension с подходящим форматом. Это намеренное безопасное поведение, а не подтверждение рабочего перенаправления таких потоков.

## Проверка

Исходный архив основан на версии 2.2. В этой среде сборка Windows DLL и проверка на Creative Sound Blaster X-Fi не выполнялись.
