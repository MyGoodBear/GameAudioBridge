# Game Audio Bridge 2.0 — отключена предварительная проверка расширений OpenAL

- Убрана предварительная проверка `AL_EXT_MCFORMATS` и `AL_EXT_float32`.
- Для многоканального Float32 потоков подходящие значения форматов OpenAL теперь передаются напрямую без отказа из-за отсутствующей строки расширения.
- Добавлено логирование фактической ошибки `alBufferData`, если runtime действительно отвергает формат.
- Не выполняются downmix, изменение разрядности или ресемплинг в точном WASAPI→OpenAL пути.
- Ограничения представления данных сохраняются: экспериментальный PCM-мост напрямую передаёт Float32 или PCM16 и 1/2/4/6/7/8 каналов. Другие кодировки не преобразуются автоматически.

Это изменение отключает только предварительные проверки строк расширений. Оно не доказывает, что любой формат поддерживается конкретной версией runtime/драйвера; окончательный результат определяется фактическим вызовом OpenAL. Пакет исходного кода не был собран и протестирован в Windows в этой среде.
