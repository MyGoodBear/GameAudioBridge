# Games Audio Bridge 2.6

Экспериментальный Windows-проект для исследования перенаправления игрового звука в OpenAL и ASIO. См. `CHANGELOG_2.6_RU.md` и `BUILDING_RU.md`.

**Важно:** в текущем исходном коде нет полноценной реализации DirectSound3D-to-OpenAL. Существующий hook работает с отдельными WASAPI/FMOD путями. Не считайте проект готовым перехватчиком DirectSound3D, пока не добавлен COM proxy DirectSound и не проведены тесты в реальных играх.

Сборка: запустите `build.ps1` в Developer PowerShell для Visual Studio 2022 с CMake 3.21+. Полученные артефакты помещаются в `dist`. Сборка и запуск требуют Windows; эта поставка содержит исходный код, а не проверенные бинарники.
