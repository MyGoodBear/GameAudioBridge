# Game Audio Bridge 1.8 — исправление удаления через контекстное меню

## Исправлено
- Контекстное меню правой кнопки мыши теперь удаляет записи только из того списка, по которому был выполнен щелчок.
- Если щёлкнуть правой кнопкой по уже выделенной строке, сохраняется множественное выделение внутри этого списка; если строка не была выделена — выделяется только она.
- Контекстное меню больше не вызывает общий обработчик кнопки «Удалить», который собирал выбранные элементы сразу из обоих списков и мог использовать устаревшее выделение второго списка.
- Список записей для удаления фиксируется до показа подтверждения; перед удалением повторно проверяется, что записи всё ещё присутствуют в конфигурации.
- Кнопка «Удалить» сохранена с прежним поведением: удаляет выбранные записи из обоих списков.
- Убран вызов Dispose() контекстного меню из обработчика Closed, чтобы не выполнять дополнительное уничтожение объекта во время закрытия меню.

## Проверки и ограничения
- Проверена структура исходного кода и наличие нового маршрута обработки контекстного меню.
- Архив проверен на целостность.
- Сборка C# под Windows в этой среде не выполнялась; исправление требует проверки запуском GUI на Windows.
